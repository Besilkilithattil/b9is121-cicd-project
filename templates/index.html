THE PROJECT, EXPLAINED

Built to be explored.

B9IS121 · MSc Cybersecurity
01 / THE APP

Simple at its core.

Flask serves this dashboard and two JSON endpoints. Gunicorn runs it inside a non-root Docker container. The interface adds no database or account system.

Explore the application
02 / THE SECURITY

Identity over passwords.

The deployment uses GitHub OIDC to sign in to Azure. A separate managed identity pulls the private image. Registry admin credentials are disabled.

Read the design notes
